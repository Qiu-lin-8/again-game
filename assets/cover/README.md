# 游戏封面目录

本目录用于存放游戏开始界面的封面素材。

## 推荐文件

`game-cover.webp`

- 推荐比例：16:9（与 Canvas 960×540 一致）
- 推荐格式：WebP（也支持 PNG / JPG，保留原格式即可）
- 推荐尺寸：1920×1080 或更长边不小于 1280px

## 当前状态

> **⚠️ 占位模式**
>
> 截至本次提交，正式封面素材尚未放入本目录。
> 游戏开始界面会显示一个明确标记为「COVER PLACEHOLDER · 占位」的回退画面，
> 并在浏览器控制台输出提示。将真实封面文件放到本目录后，无需改动任何代码即可自动显示。

## 整合方式

`index.html` 的开始界面 overlay 内含 `#gameCover`：

- 正常加载时显示封面图，隐藏占位；
- 加载失败时隐藏图片、显示占位（带 COVER PLACEHOLDER 标记）；
- 仅在 `.mode-menu`（开始界面）显示，结算 / 游戏中不显示。

封面图通过 `object-fit: cover` 等比裁剪，不拉伸变形，手机和电脑均正常显示。
